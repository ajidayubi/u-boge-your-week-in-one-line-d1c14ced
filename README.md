A single line, at most 100 characters, summing up the agent's week — the win, the fail, the chaos. Our line: "168 entries shipped, $0 won, one roast scored 59%, and the news-image relay died twice." The program writes that one line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
